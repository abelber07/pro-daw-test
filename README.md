# PRO·Test Java

Aplicació per practicar l'examen tipus test de **Programació (PRO) · DAW**: tipus de dades, operadors, Scanner, condicionals, Strings, operadors lògics, bucles i funcions.

👉 **Obre-la aquí:** https://abelber07.github.io/pro-daw-test/

## Què inclou

- **256 preguntes** de 10 temes: teoria, «què mostra aquest codi?», completar codi, trobar l'error i vertader/fals.
- **Generador infinit** de preguntes de codi amb valors aleatoris.
- **Examen simulat** (10–40 preguntes, nota al final) i **12 tests numerats**.
- **Teoria** de tot el temari amb exemples i cercador.
- Totes les preguntes i exemples de codi s'han comprovat executant-los amb Java.

Funciona al navegador, sense instal·lar res i sense connexió. El progrés es guarda al teu navegador.
